# SQL-Practical-Test# 🛒 E-Commerce Order Management System

## 📌 Project Overview
The **E-Commerce Order Management System** is a MySQL-based database project designed to manage the core operations of an online shopping platform. It organizes product details, customer information, orders, payments, and shipping records in a structured database.

## 🎯 Key Features
- **Product Management:** Store product and category details.
- **Customer Records:** Maintain customer information.
- **Order Processing:** Manage orders and their items.
- **Payment Tracking:** Store payment details and statuses.
- **Shipping Management:** Maintain shipment information.
- **Data Analysis:** Generate useful reports using SQL queries.

## 🛠️ Technologies Used
- **Database:** MySQL
- **Language:** SQL
- **Tools:** MySQL Workbench / MySQL Command Line

## 📚 SQL Concepts Covered
- Database and table creation
- Primary and foreign keys
- CRUD operations
- Filtering and sorting records
- Aggregate functions and grouping
- Joins and subqueries
- Date and string functions
- CASE statements
- Common Table Expressions (CTEs)
- Window functions

## ▶️ How to Run
1. Open MySQL Workbench or your preferred MySQL client.
2. Create or open a new SQL query tab.
3. Copy and execute the project SQL script.
4. Run the SELECT queries to view the stored data and reports.

**Requirement:** MySQL 8.0 or later is recommended for CTEs and window functions.

## 📊 Expected Output
The project produces structured results such as:
- Product and category listings
- Customer and order details
- Order-wise item information
- Payment and shipping records
- Sales summaries and analytical reports

## 💡 Learning Outcomes
This project demonstrates how SQL can be used to design relational databases, maintain data consistency, retrieve connected information, and analyze order-related data.
